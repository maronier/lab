# Prompt Design Utilities

Небольшой демонстрационный проект с CLI-командами.

## Запуск

```bash
python main.py <command>
# или
python -m main <command>
```

Доступные команды:

- `sys` — проверка окружения Python и свободного места.
- `weather` — погода для фиксированных координат.
- `monitor` — мониторинг CPU/RAM/диска в реальном времени.
- `blush` — мини-демо по подбору оттенка румян под тип кожи.

## Пример для демо румян

```bash
python main.py blush
```

Программа задаст 3 вопроса (глубина тона, подтон, тип кожи) и даст рекомендацию по:

- цветам румян;
- текстуре;
- базовому способу нанесения.
